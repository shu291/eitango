# DESIGN.md — 英単語マスター の見た目のルール

実装中に迷ったらここを見る。ここに書いていないことは勝手に決めていい。
ここに書いてあることは**必ず守る**。

## 方向性

- 採用案: **A「英単語ノート」**（`design/design-brief.html` で3案を見くらべられる）
- 雰囲気: 生成り / 罫線 / 朱の一点
- なぜ: 朝の通学電車でも夜9時の机でも眩しくない生成りの紙面に、英単語だけがセリフ体で罫線の上に立つので、
  一番見たいもの（次に覚える綴り）が毎回まっ先に目に入る
- 使う場面: 朝の電車で片手・数分／夜の自室の机で数十分
- 2位案「辞書の見開き」から**罫線で段差を作る組版**を、3位案「まるシール」から
  **押せるもの＝色の面がある／読むだけ＝罫線だけ**という規則を取り込んである

## 色

> ⚠️ **【2026-08-30】色だけ刷新前に戻した（本人の希望）。**
> 下の表の「使うもの」「className」「JS から」「使いどころ」はそのまま生きているが、
> **実際に出る色は生成り・藍・朱ではなく、Tailwind 既定の indigo / rose / emerald / amber**。
> 名前（paper / sheet / navy / vermilion …）は変えていないので、コードの書き方は変わらない。
> 現物の値は `src/theme.js` の冒頭を見ること。組み方のルール（影ゼロ・罫線で段差・
> 押せる＝色の面）は下のとおり有効。

値は **`src/theme.js` が唯一の出どころ**。`tailwind.config.js` もそこを読んでいる。
**16進数のカラーコードを画面のコードに直接書かない。**

| 使うもの | className | JS から | 使いどころ |
|---|---|---|---|
| 紙の地 | `bg-paper` | `C.bg` | 画面全体の背景 |
| 紙片 | `bg-sheet` | `C.surface` | カード・パネルの背景 |
| 罫線 | `border-rule` | `C.border` | 区切り・カードの枠 |
| インク | `text-ink` | `C.text` | ふつうの文字 |
| 鉛筆 | `text-ink-soft` | `C.muted` | 補足・単位・日付 |
| 藍 | `bg-navy` `text-navy` | `C.primary` | **押せるもの**・進捗・選択中 |
| 藍の上の文字 | — | `C.onPrimary` | 藍のボタンの中の文字 |
| 朱 | `text-vermilion` | `C.accent` | **赤ペンの印**（間違い・苦手・期限超過・削除） |
| 苔 | `text-moss` | `C.success` | 正解・完了 |
| 代赭 | `text-ochre` | `C.ochre` | 保存/読込など「注意ではない」印 |

### 色の意味を混ぜない（審査で一番指摘されたところ）

- **藍 = 押す。朱 = 間違い。** 同じ色を両方の意味に使わない。
- 朱は1画面に1〜2か所まで。全部に印を付けると赤ペンの意味が消える。
- 覚え具合は**虹色をやめ、藍1色の濃淡**で表す（濃いほど覚えている）。
  例外は「要復習」だけで、ここは朱＝赤ペンでチェックした行という別の意味。値は `getLevel()`。

### 既存の色名は読み替えてある

`tailwind.config.js` で Tailwind の既定色を紙の色に差し替えてある。
`bg-white` は生成りの紙片、`bg-indigo-600` は藍、`text-rose-500` は朱、`text-gray-400` は読める濃さの鉛筆になる。
**書き忘れても紫や水色は出てこない。** 新しく書くところは上の表の名前を使う。

## 文字

英単語と数字だけ Google Font を当てる。**日本語には当てない**（豆腐や偽の太字になる）。
`@expo-google-fonts/lora` と `@expo-google-fonts/ibm-plex-mono` を同梱済みで、通信は発生しない。

| 用途 | 書き方 |
|---|---|
| 英単語（大きく見せる） | `style={{ fontFamily: F.enBold }}`（= Lora 700） |
| 英単語（一覧の行） | `style={{ fontFamily: F.enSemi }}`（= Lora 600） |
| 数字・％・タイマー | `style={NUM}` / `style={NUM_BOLD}`（IBM Plex Mono + 桁がずれない指定） |
| 日本語 | 何も指定しない（システム書体のまま） |

### 禁止

- **13px 以下に Lora を当てない。** 線が細くなって生成り地に埋もれる。12px の補足は日本語書体のまま。
- `fontFamily: F.enBold` と `font-bold` を**同時に使わない**（iOS で二重に太くなってにじむ）。
- **11px 以下を使わない。** 最小は 12px。
- **文字サイズを書き忘れない。** 書かないと 14px になり、見出しと本文が同じ大きさになる。

| 段階 | className | px | 使う所 |
|---|---|---|---|
| 特大 | `text-4xl` / `text-3xl` | 36 / 30 | フラッシュカードの英単語、結果の点数 |
| 大 | `text-2xl` | 24 | 画面の見出し |
| 中 | `text-lg` | 18 | セクションの見出し |
| 標準+ | `text-base` | 16 | カードの見出し・単語一覧の英単語 |
| 標準 | `text-sm` | 14 | 本文 |
| 小 | `text-xs` | 12 | 補足・ラベル。**これより小さくしない** |

- 折り返す日本語には行間を付ける（`style={{ lineHeight: 19 }}` / 14px なら 21）。指定しないと詰まって読みにくい。

## 余白と形

- 余白は **4 / 8 / 12 / 16 / 24 の5段だけ**（`SP[1]`〜`SP[5]`）。`6px` `10px` `14px` を書かない。
- **画面の左右は 16px。ヘッダも本文も同じ値**にする（ヘッダだけ 20px にしない）。
- カード同士の間は 12px、セクションとセクションの間は 24px。
- カードの内側は **16px に統一**。特別に主役の1枚だけ 24px を許す。
- 角丸: カード `rounded-lg`(10) / ボタン `rounded`(6) / 小物 `rounded-sm`(2) / チップ `rounded-full`
- **タップできるものは高さ 44px 以上。** 入力欄も `py-3` 以上にする。

### 段差の作り方 — 影は使わない

```
❌ style={{ shadowColor:'#000', shadowOpacity:0.05, shadowRadius:4 }}
✅ <Sheet> を使う（bg-sheet + border-rule + rounded-lg）
```

- 影は全画面ゼロ。段差は **1px の罫線**と、紙 `#F7F3E9` と紙片 `#FFFDF7` のわずかな色差で作る。
- 影を捨てたぶん、**本当に浮いているものだけ**手当てする:
  下タブは上辺 **2px** の罫（`border-rule-strong`）、モーダルの背面は `rgba(34,32,27,.5)` で沈める。
- **いま見てほしい1ブロック**は `<Sheet mark={C.primary}>` で左端に3pxの縦罫を入れる＝赤ペンで囲んだ段差。
  朱 `C.accent` は「期限超過・苦手」の行にだけ。

### 押せるかどうかを見た目で言う

- **押せる** → 藍のベタ塗り（`<Btn tone="navy">`）か、藍の枠だけ（`tone="line"`）。
- **読むだけ** → `<Sheet>`（罫線だけ・色の面なし）。
- 1画面のベタ塗りボタンは**原則1つ**。それが「次にやること」になる。

## 共通パーツ（App.js の上のほうに置いてある）

| パーツ | 用途 |
|---|---|
| `<Rule />` | 罫線1本 |
| `<Sheet mark={色}>` | カード。`mark` で左端の縦罫 |
| `<SectionTitle icon right>` | カードの中の見出し |
| `<PageTitle title sub right>` | 画面の顔（紫のベタ帯の代わり） |
| `<Header title back right>` | 戻る矢印つきの上部バー |
| `<Btn label tone icon small disabled>` | ボタン |
| `<EmptyState title body actionLabel onAction>` | 空っぽの画面 |
| `<LvBadge w>` | 覚え具合のしるし |

**新しくカードやボタンを書かない。上のパーツを使う。**

## アイコン

- `@expo/vector-icons` の **Ionicons** に統一（`brain` など一部だけ MaterialCommunityIcons）。
  追加する名前は `App.js` の `MCI_NAMES` に足す。
- **絵文字とアイコンを同じ画面に混ぜない。** 見出しの 📚 🎯 💾 🗂 は使わない。
  絵文字を出していいのは本文の中だけ（「今日の復習は終わりました 🎉」など）。
- 意味のないアイコンには `aria-hidden` 相当（`accessibilityElementsHidden`）、押せるものには `accessibilityLabel`。

## 空っぽの画面

**全画面に必ず1つ用意する。** `<EmptyState>` を使い、「何をすればいいか」の一言と次の行動のボタンを1つ添える。

- 単語0件 → 「このノートはまだ白紙です」＋「単語を書き込む」
- 検索0件 → 「『◯◯』に一致する単語はありません」＋「検索をやめる」
- 出題できる語が0 → 学習画面で `return null` しない（真っ白になって戻れなくなる）。ヘッダ付きで理由を出す。

## 動き

- 押した感: `activeOpacity={0.75}`。RN の Web では `:active` が使えないのでこれで代用する。
- 判定の見せ方: 正誤を見せてから次へ進む。待ち時間は実装済みの値がそのまま正で、
  **4択クイズ 900ms / スピード 350ms / マッチング完了 500ms**（`App.js` の `setTimeout`）。
  ここを短くすると正解を読み切る前に次の問題へ飛ぶので、数字を勝手にそろえない。
- 時間は 0.12〜0.3 秒。それ以上は「重い」と感じる。

## React Native でやってはいけないこと（すでに踏んだ罠）

- `height:'100%'` は Web で 0px になる。`flex:1` を使う。
- CSS の `color-mix()` / `linear-gradient()` は使えない。半透明は 8桁 HEX（`#1F3A5F29`）。
- 影は className では効かない。そもそもこの案では使わない。
- Web では `Alert.alert` が無反応。`src/lib/confirm.js` を通す。
- 数字には `fontVariant:['tabular-nums']`（`NUM` / `NUM_BOLD` に入っている）。

## 写真について

この案では**写真を使わない**。単一バンドルで配る前提なので外部URLを持ちたくないのと、
空っぽの画面は写真ではなく「罫線だけ引いた白紙」の絵（`<EmptyState>` の中で描いている）で表しているため。
表紙写真だけは本棚の機能なのでそのまま残す。
